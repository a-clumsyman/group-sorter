Group Sorter

Starting up

1

Link the bot’s WhatsApp number

Use a spare number for the bot, not your personal one. WhatsApp does not officially allow bots in groups, so there is a small chance the number gets blocked.

Getting a code from WhatsApp…

  1. Open WhatsApp on the bot’s phone.
  2. Go to Settings, then Linked devices.
  3. Tap Link a device and scan this code.

Now make this number an admin in every group you want sorted. It needs to be an admin to remove a misplaced post.

2

Add the AI key

The bot asks Claude, an AI model, to read each post and work out what it is about. Create a key at console.anthropic.com under API keys, add a little credit there, and paste the key here. You pay Anthropic for what the bot uses.
